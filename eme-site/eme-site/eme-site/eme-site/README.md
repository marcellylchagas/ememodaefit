# EME Moda & Fit · loja (versão de teste)

Site estático da loja EME Moda & Fit, publicado no Netlify.

- `index.html`: a loja inteira (vitrine, produtos, sacola e finalização pelo WhatsApp).
- `banner*.jpg` e `cat-*.jpg`: banners e capas das categorias.
- `manifest.webmanifest` e `icone-*.png`: instalação no celular.
- `netlify.toml`: configuração do Netlify.

Esta versão usa produtos de exemplo e não tem o painel. O painel volta quando o Supabase for ligado.
